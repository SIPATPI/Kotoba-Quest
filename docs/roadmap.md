# Roadmap — แผนพัฒนา Kotoba Quest

**สถานะ: In Development / Staging**

Kotoba Quest ยังเป็นเว็บแอประหว่างพัฒนา ไม่ใช่ผลิตภัณฑ์ที่เปิดตัวในตลาดแล้ว เป้าหมายคือค่อย ๆ ทำให้ระบบเสถียรและเพิ่มเนื้อหาที่ผู้เรียนใช้ได้จริง ก่อนต่อยอดเป็นแอปมือถือ

## มีหลักฐานในเอกสาร/ตัวอย่างที่เผยแพร่

- มีเว็บเวอร์ชัน staging ที่ Vercel
- มีหน้าและแนวคิด Boss Battle พร้อมภาพการเล่น
- มีการแยกเส้นทางการเรียน Sakura / Minna ในตัวอย่างโค้ด
- มี logic สำหรับแนะนำให้กลับไปทำบทเรียนหรือศึกที่ค้างอยู่ในตัวอย่างโค้ด
- มีตัวอย่างการป้องกันคำตอบซ้ำและการทดสอบในเอกสาร public

รายการนี้ไม่ได้ยืนยันว่าฟีเจอร์ทุกส่วนผ่านการทดสอบ end-to-end แล้ว

## กำลังให้ความสำคัญ

- [ ] ทดสอบและปรับปรุงความเร็ว/ความเสถียรในเส้นทางเล่นจริง
- [ ] ตรวจการเข้าสู่ระบบ การกลับมาเล่น และการบันทึกความคืบหน้า
- [ ] เพิ่มคำศัพท์ ไวยากรณ์ การอ่าน และบทเรียนที่เหมาะกับผู้เริ่มต้น
- [ ] ปรับสมดุลระบบ Boss Battle และทำให้การใช้ความรู้จากบทก่อนหน้าชัดขึ้น
- [ ] ปรับ UI สำหรับมือถือและทดลองกับผู้ใช้งาน

## เป้าหมายระยะยาว

- [ ] ทดลองให้ผู้เรียนภาษาญี่ปุ่นใช้และเก็บความคิดเห็น
- [ ] ปรับบทเรียนและระบบเกมจากการใช้งานจริง
- [ ] พัฒนาและเตรียมเปิดให้ใช้ในรูปแบบ Mobile Application
- [ ] ศึกษาความเป็นไปได้ในการนำผลิตภัณฑ์ออกสู่ตลาด
